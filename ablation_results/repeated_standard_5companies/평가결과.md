# 기업별 BERTScore 평균 및 표준편차

각 기업·조건의 3회 실행 BERTScore F1을 평균 ± 표본 표준편차(n=3, 분모 n−1)로 표시했다. 기존 1회 점수와 추가 2회 점수를 사용했다. 전체 평균 행의 표준편차는 각 실행에서 5개 기업 점수를 평균한 뒤, 그 3개 평균값으로 계산했다.

실제 애널리스트 보고서와 생성 보고서의 서술 본문을 비교했다. 표·차트·예측 재무제표 표·안내문은 제외하고 서술형 전망은 포함했다. 기존 BAAI/bge-m3 24층 설정(IDF·기준선 재조정 없음)을 유지했으며 본문을 자르지 않았다. 유료 API 호출은 없다. 정밀도·재현율과 실행 간 표준편차는 CSV에 보존했다. 이 점수는 본문 의미 유사도이며 분석 정확성이나 투자판단 품질을 직접 측정하지 않는다.

아모레퍼시픽 3회차 One-team은 차트 근거 연결 2건만 오프라인 복구했으며 평가 본문은 수정되지 않았다.
