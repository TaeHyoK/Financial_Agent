# Ablation 조건 정렬 구현 기록

> 후속 실호출(2026-09-09): [소규모 실행 기록](../../ABLATION/experiments/annual_pilot_20260909_v2/pilot_execution.md). 공통 자료 준비를 실행했으나 코웨이 Strategy의 본문 인용 근거 15개가 후처리 상한 10개와 충돌했다. 추가 호출을 중단했으며 다섯 조건 실험은 아직 시작하지 않았다. 아래 ‘실호출 미수행’은 최초 구현 시점의 기록이다.

작성일: 2026-09-09. 작업 대상: `FINAL`, `ABLATION`.

코드 수정과 오프라인 검증을 마쳤다. 새 기준일 자료 수집, 유료 생성·평가, Git 반영은 하지 않았다. 기존 보고서와 실험 결과는 변경하지 않았다.

## 1. 반영 내용

| 항목 | 변경 |
|---|---|
| one_team 완료 처리 | 미정의 `scaffold_command` 참조를 제거하고 바깥 실행기에서 명령을 기록한다. 보고서 발행·성공 반환·사용량 마감을 함께 검사했다. |
| Full/one_team | Full의 재무·뉴스·시장 요청 생성 함수를 공유한다. 도메인 지침·입력·스키마·보조자료 평가와 결과 반영 함수를 재사용한다. 통합 전용 `cross_domain`과 사용하지 않는 요약 출력은 제거했다. |
| 공시 | 연결재무제표를 우선 추출한다. 연결이 없는 경우 별도를 사용하며, 연결 파싱 실패를 별도로 숨기지 않는다. 회계 범위·기간·접수일을 보존하고 범위가 다른 값의 성장률·TTM 계산은 제외한다. |
| 재무 이력 | 최근 사업보고서의 비교 열부터 사용한다. 3개 연도 중 누락이 있으면 기준일 전에 공개된 과거 사업보고서를 최대 2개 더 조회한다. 새 공시의 값을 과거 공시로 덮어쓰지 않고 부족한 연도만 보충한다. 확보된 연도는 `annual_history_coverage`에 기록한다. |
| 계정명 | 지배주주 귀속 이익·자본을 별도로 보존한다. 같은 ‘지배기업소유주지분’이라도 순이익과 포괄이익 아래의 값을 구분한다. 반기·분기 연결순이익 계정명도 지원한다. |
| 가치평가 | 연결 PER·PBR은 지배주주 귀속 이익·자본을 사용한다. 종가와 공시 보통주 발행주식 수로 계산한 값은 추정치로 표시한다. 주식 종류·공개일·가격 시점·관측된 분할이 맞지 않으면 계산하지 않는다. 제공업체의 과거 지표는 당시 이용 가능성이 검증된 값으로 취급하지 않는다. |
| Strategy | 향후 12개월 Buy +15% 이상, Hold -15% 초과~+15% 미만, Sell -15% 이하를 공통 해석 기준으로 제공한다. 목표주가·예상 수익률 산출을 강제하거나 Python이 의견을 재분류하지 않는다. |
| 본문 평가 | PDF의 고정 본문 영역과 HTML의 서술 문단·목록을 비교한다. 표·차트·고지문은 제외하고 전망을 설명하는 문장과 그 숫자는 유지한다. ROUGE-L·BERTScore·NumberRate에 같은 본문을 사용한다. |

`random_news`, `no_subdata`, `no_peer`의 실험 정의는 유지한다. 중요 사건 누락 평가는 추가하지 않았다.

## 2. 공통 호출 설정

도메인 분석 설정은 `src/shared/domain_llm.py`에서 관리한다.

- 모델: GPT-5.4. Responses API, 추론 `none`, 온도 0.2, 출력 상세도 `medium`.
- 출력 상한: Full 도메인별 12,000토큰, one_team 기업별 36,000토큰. 최대 예산을 맞춘 것이며 실제 사용량이 같다는 뜻은 아니다.
- 시간 제한: 기본 300초, 실행기의 공통 시간 제한을 반영한다.
- 일시적 통신 오류만 최대 3회 시도한다. 불완전 응답·형식 오류로 투자 내용을 다시 작성시키지 않으며, 응답 사용량은 파싱 전에 기록한다.
- one_team도 대상기업과 비교기업을 각각 분석한 뒤 같은 비교 분석·Strategy·Writer로 전달한다.

one_team은 한 문맥에서 모든 도메인의 상세 주 자료를 볼 수 있다. 개별 에이전트의 정보 접근 경계까지 동일한 실험은 아니며, 역할 분리·문맥 공유·호출 수의 차이가 함께 포함된다.

새 버전은 `annual_report_dates_v2_common_contracts`, `unified_domain_team_v7_common_contracts`다. 코드·모델·시간 제한·자료 해시를 작업 식별에 반영하므로 기존 실험을 새 결과와 혼용하지 않는다.

## 3. 평가 범위

`ABLATION/real_report_evaluation/reference_regions.json`에 참고 PDF 6개의 파일 해시와 본문 영역·순서를 저장했다. 모든 조건에 같은 설정을 사용한다. 현대모비스 5·6쪽의 실적발표 질의응답과 아모레퍼시픽 2쪽으로 이어지는 본문도 포함한다. 수정되거나 새로 추가된 PDF는 영역 검토 없이는 평가하지 않는다.

본문 버전은 `narrative_body_v1`이다. 원문 추출문·정제 본문·길이·영역 설정 해시를 결과에 남긴다. 투자의견 일치도는 기존 명시적 등급 추출 경로를 유지하며 본문 유사도와 분리한다.

BERTScore의 앞 510토큰 제한을 없앴다. 로컬 `BAAI/bge-m3` 토크나이저 한도는 특수 토큰 포함 8,192개이며, 확인한 참고 본문 6개는 이 범위 안이다. 실제 BERTScore 인코딩 경로도 대조해 조용한 잘림을 차단한다. 한도 초과 시 부분 본문 점수를 내지 않고 평가를 중단한다. `--reference-max-pages`는 0, `--bert-max-tokens` 기본값은 0(토크나이저 한도)이다. 이전 표 포함·510토큰 점수와 섞지 않는다.

## 4. 검증 결과와 남은 일

- FINAL 33개, ABLATION 73개 테스트 통과. API 응답은 모의 응답이며 유료 호출은 없다.
- 저장된 실제 공시 XML 14개의 연결·별도 선택을 확인했다. 코웨이·SK바이오팜은 매출·순이익·지배주주 이익·자본을 추출 결과와 원문 행으로 대조했다. 이는 저장된 2025년 반기 공시 검사이며 새 기준일 데이터 검사는 아니다.
- 참고 PDF 6개 전 페이지를 렌더링해 본문 영역을 정하고 추출문을 대조했다. 생성 HTML의 표·차트·고지문 제외 및 전체 본문 전달은 테스트했다. 새 보고서의 BERTScore 점수는 계산하지 않았다.
- `--protocol annual --companies all --plan-only` 확인 결과, 새 기준일의 공통 자료는 6개 기업 모두 미준비다.

남은 순서는 다음과 같다.

1. 코웨이·SK바이오팜의 새 기준일 대상·비교기업 자료 준비. 공시 본표·사업별 매출의 범위, 3개년 확보 여부, 가치평가 입력을 확인한다.
2. 동일한 공통 자료를 고정하고 두 기업 × 다섯 조건 × 1회 실행. 실제 입력 차이, 생성량·근거 전달·보고서 내용·비용을 확인한다.
3. 공통 설정을 확정한 뒤 6개 기업 × 다섯 조건 × 3회 본 실험. 설정 변경 전 결과와 혼용하지 않는다.

주식 종류를 확인할 수 없는 표를 보통주로 추정하지 않는다. 예를 들어 저장된 SK바이오팜 공시는 주식 수를 의결권 유무로 표시해 현재 추출기에서 보통주 여부를 확정하지 못하므로 시가총액 기반 배수를 계산하지 않는다. 공시 후 주식 수 변동과 제공업체의 사후 가격 조정도 완전히 복원한 것은 아니다. 새 자료에서 결측과 한계를 확인하되, 다른 조건에만 대체값을 넣지 않는다.

오프라인 테스트 통과는 실호출 성공이나 Full 성능 우세를 보장하지 않는다. Full 우세는 검증할 가설이며 실행 통과 조건이 아니다.
