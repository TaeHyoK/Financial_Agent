# 12개월 분석 설계

현재 뉴스 입력은 [뉴스 주 자료와 월별 요약 보조자료](news_article_only.md)를 따른다. 뉴스 분석에는 선정 기사 전체를, 재무·시장 보조자료에는 월별 요약을 제공한다. 아래 최초 설계의 전체 상위 20건·요약 하드 상한 설명은 현재 기본값이 아니다.

기준일은 장 시작 전이다. 뉴스·시장 데이터는 전날까지, DART는 기준일 전에 접수된 정기공시만 사용한다. 예를 들어 기준일이 2025-10-31이면 뉴스·시장 분석 범위는 2024-10-31~2025-10-30이고 투자 전망은 기준일 이후 12개월이다. 수집 기간과 미래 판단 기간을 구분한다.

## 데이터와 공통 subdata

| 자료 | 주 분석 입력 | 다른 두 에이전트에 전달하는 subdata |
|---|---|---|
| 뉴스 | 과거 1년의 월별 요약 12개 + 전체 상위 사건 최대 20건 | 같은 월별 요약 12개 |
| 시장 | 과거 1년의 지표·월별 관측치 12개 + 최근 20거래일 | 같은 시장 지표표 1개 |
| 재무 | 최신 정기공시·전년 같은 기간·3개 연도 재무제표와 사업 내용 | 같은 8개 지표의 재무 추세표 1개 |

수신자별 선별이나 별도 요약 에이전트를 추가하지 않는다. `src/shared/subdata.py`의 공통 함수로 같은 자료를 생성한다. 각 에이전트의 결론은 담당 자료를 근거로 작성하고 다른 자료는 정합성·충돌·해석 한계를 점검하는 문맥으로 사용한다.

### 뉴스

주별 중복 병합 후 공시 섹션별 임베딩 유사도의 가중합으로 최대 3건을 직접 선정한다. 교차 인코더 재정렬은 사용하지 않는다. 선정된 사건을 월 구간으로 다시 묶어 요약한다. 중간 날짜를 기준일로 삼아도 1년을 빠짐없이 다루도록, 매달 기준일에 대응하는 날짜를 경계로 12개 구간을 만든다. 예: 2024-10-31~2024-11-29, …, 2025-09-30~2025-10-30. 달마다 1일부터 말일까지의 달력월과는 다르며 실제 시작·종료일을 명시한다. 윤년과 월말은 달력에 맞춰 보정한다.

- 요약당 2~4문장·400자 이내를 요청한다. 600자를 넘거나 기간이 누락·중복되면 실패 처리한다. 핵심 이슈는 최대 3개다.
- 비어 있는 월은 선별된 뉴스가 없음을 기록한다. 이것을 해당 월에 사건이 전혀 없었다는 뜻으로 해석하지 않는다.
- 구체적 사건은 `NEWS_RAW`, 요약된 기간 흐름은 `NEWS_PERIOD`로 구분한다. 요약을 원문 직접 확인으로 승격하지 않는다.
- Strategy와 Writer까지 요약 기간을 보존한다. 월별 요약의 종료일을 사건 발생일로 표시하지 않으며, 원문 근거의 보도일도 사건 발생일과 구분한다.
- 전체 출처 연결은 `llm_period_summaries.json`의 `source_event_ids`에 보관한다. 공통 subdata에는 월별 근거 ID·기간·요약·출처 건수를 넣어 긴 ID 목록의 반복을 피한다.
- 1년치 수집·임베딩 및 요약 생성 비용은 늘 수 있다. 최종 분석 입력을 제한한다고 전체 실행 비용이 고정되는 것은 아니다.

### 시장 지표표

| 지표 | 정의 / 표시 |
|---|---|
| 주가 수익률 | 1·3·6·12개월, % |
| KOSPI 수익률 | 같은 1·3·6·12개월, % |
| 시장 대비 초과수익률 | 주가 수익률 − KOSPI 수익률, %p |
| 1년 변동성 | 일별 수익률 표본 표준편차 × √252, % |
| 1년 최대 낙폭 | 1년 내 이전 고점에서의 최대 하락폭, 음수 % |
| 현재 낙폭 | 현재 종가 / 1년 내 최고 종가 − 1, % |
| 최근 거래량 배율 | 최근 5거래일 평균 / 60거래일 평균, 배 |

16개 숫자와 실제 기준 거래일·종가·벤치마크·산식을 함께 전달한다. 기간 수익률은 최신 거래일에서 달력 개월 수를 빼고 그 날짜 또는 직전 거래일의 종가를 기준으로 계산한다. 배당을 제외한 공급자의 분할조정 종가를 주식과 지수에 일관되게 사용한다. 과거 1년보다 짧은 상장 이력 등으로 계산할 수 없으면 결측으로 남긴다.

120·200일 이동평균 대비 위치와 최근 20거래일 이동평균 변화, 1년 가격 범위 내 위치도 시장 주 분석에 제공한다. 지표 계산을 위해 기존 2년 이상 준비 데이터를 유지하며, 분석 범위는 1년으로 자른다. 월별 관측치의 첫 구간에 직전 종가가 없으면 첫 관측 종가를 사용했다는 상태와 실제 가격 날짜를 표시한다.

### 재무 추세표

행은 매출액, 매출 증가율, 영업이익, 영업이익률, 순이익, 영업현금흐름, 자본총계, 부채비율이다. 열은 최신 3개 연도와 최신 누적 실적·전년 같은 누적 실적이며, 연간 보고서가 최신이면 같은 연도 열을 중복하지 않는다.

금액은 억원, 비율은 %다. 영업이익률은 영업이익/매출, 부채비율은 총부채/자본총계다. 자본이 0 이하이면 부채비율은 결측으로 처리한다. 비교할 이전 기간이 없는 매출 증가율 역시 결측이다. 연간 실적과 반기·분기 누적 실적을 직접 비교하지 않으며, 자본·부채는 해당 기말의 잔액이다. 대상 기간, 접수일, 공시 번호와 연결/별도 범위를 보존한다.

`Financial/{기준일}/financial_subdata.json`과 `Y_Finance/{기준일}/market_subdata.json`에서 표의 구조를 확인할 수 있다. 뉴스 월별 요약은 `News/{기준일}/context_exports/month/llm_period_summaries.json`에 저장한다.

최신 공시가 사업보고서일 때도 직전 연간 공시와 비교한다. 중간 연도가 빠져 있는 연간 자료끼리는 전년 대비 증가율을 계산하지 않는다. 시장 월별 관측치는 상장 이력이 짧아도 12개 구간을 유지하며, 관측치가 없는 구간은 결측과 `unavailable`로 표시한다.

## Strategy와 최종 보고서

기본 프로필은 `annual`, 판단 기간은 `12개월`이다. Strategy v5의 개정 식별자는 `schema_revision: 12m_v1`이며 기존 캐시는 다시 생성한다.

`strategy_brief`에는 `headline`, `recommendation`(Buy/Hold/Sell), `thesis`, `earnings_review`, `outlook`, `price_assessment`, `counterview`, `decision_limitation`을 담는다. 문장별 근거 연결을 유지한다. 목표주가·미래 EPS·컨센서스는 필수 조건이 아니며 없는 숫자를 생성하지 않는다. 의견은 어느 등급도 기본값으로 강제하지 않는다.

실제 보고서의 제목·투자의견·실적 검토·전망 구성을 참고하여 최종 HTML에 다음 내용을 표시한다.

1. 핵심 제목, 매수/중립/매도 의견과 12개월 판단 기간
2. 투자 의견과 핵심 논거
3. 최근 실적과 가격 평가
4. 핵심 판단 근거 최대 3개
5. 향후 12개월 전망: 확인된 사실·전제·예상 영향을 구분
6. 핵심 위험 최대 3개와 자료 기준·한계

Writer는 Strategy 의견을 그대로 표시한다. HTML의 `investment-recommendation` 메타 필드에도 Buy/Hold/Sell을 보존하여 평가 때 문장에서 신규 진입 의사를 추정할 필요가 없게 한다. 다른 판단 기간을 명시적으로 선택하는 이전 CLI 옵션도 남아 있다.

참고 PDF는 형식 검토용이다. 기준일보다 늦은 실제 보고서를 분석 입력으로 전달하지 않는다.

## 실행과 검증

```bash
PYTHONPATH=src python -m orchestration.full_report_pipeline \
  --company-name 현대모비스 --selected-date 20251031 \
  --news-window 1y --decision-horizon-profile annual \
  --output-root Output_annual --no-progress

python -m unittest discover -s tests -v
```

오프라인 회귀 검증은 날짜·윤년·미래 데이터 제외, 수익률·위험·거래량 계산, 재무 비교와 결측 처리, 뉴스 요약 범위·근거 연결, Strategy까지의 연간 지표 전달, 세 가지 투자의견의 HTML 보존을 포함한다. 테스트용 투자 의견은 출력 계약을 확인하기 위한 값이며 실제 기업 분석 결과가 아니다.

### Ablation 공통 계산과 요약 입력

뉴스 요약 LLM에는 선택 순위·유사도 점수를 주지 않고 기사 사실과 기업의 사업 내용을 바탕으로 중요도를 판단하도록 한다. 입력 기사는 날짜·사건 ID 순으로 정렬한다. 이는 Full과 무작위 조건의 공통 처리이며, 기존 요약 결과를 소급해 바꾸지는 않는다.

`--primary-data-only`에서도 주가·DART 기반 가치평가 계산은 유지한다. 재무·뉴스 보조 입력은 시장 LLM에서 제거하고, 계산된 가치평가는 LLM 입력에 넣지 않은 채 `valuation_snapshot`으로 Strategy에 전달한다. 따라서 보조자료 제거가 계산 P/B 등의 제거를 동시에 뜻하지 않는다.

### 기존 자료 재사용 시 확인

- `--reuse-dart-data-from`은 저장된 DART 원본의 기준일과 접수일을 검증한 뒤 현재 계산기로 재무 지표와 3개 연도 subdata를 다시 만든다. 이전의 1개 연도 경량 파일을 그대로 복사하지 않는다. 재사용 원본은 수정하지 않는다.
- `--reuse-domain-data-from`은 기업·기준일·분석 기간·시장 가격 기준·연간 지표·월별 요약 구간을 확인한다. 3개월짜리 전체 자료는 1년 실행에 재사용할 수 없다. 이 경우 새로 수집하거나 DART만 재사용한다.
- 시장 manifest의 기준일도 함께 보존하고, 날짜가 붙은 최신 요약에서 공통 별칭과 시장 subdata를 만든다. 보고서 작성 직전에도 기준일 이후의 시장 관측치를 제거한다.
- 전체 시장 JSON·CSV, manifest와 subdata를 실행 결과 해시에 포함한다. 연간 자료가 바뀌었는데 요약 파일만 같아서 이전 분석 결과가 재사용되는 일을 막는다.

이번 코드 변경만으로 기존 보고서나 ablation 결과가 갱신되지는 않는다. 1년치 API 재수집과 실험을 별도로 실행해야 성능과 실제 토큰 비용을 확인할 수 있다. 실험에서는 같은 기준일·입력 기간·판단 기간을 사용하고 데이터 변경 효과와 Strategy 형식 변경 효과를 구분한다. 실제 보고서 의견과의 일치율은 미래 실현 수익률의 예측 정확도와 구분한다. `ABLATION`의 기존 신규 진입 문장 기반 평가는 새 명시적 의견 필드에 맞춰 적용해야 하며 이 변경에서는 해당 디렉터리를 수정하지 않았다.
