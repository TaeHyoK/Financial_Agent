## 1. 작업 목적과 적용 범위

기존 ablation 결과를 계기로, 실제 기업 분석 보고서의 구성과 판단 기간을 참고하여 모델의 분석 입력과 보고서 출력을 수정했다. 과거 자료를 살펴보는 기간과 앞으로 투자 판단을 내리는 기간을 구분했다.

| 구분 | 반영한 기준 |
|---|---|
| 뉴스 분석 범위 | 과거 1년 |
| 시장 분석 범위 | 과거 1년 |
| 재무 분석 범위 | 3개 연도 실적과 최신 정기공시·전년 같은 기간 |
| 투자 판단 기간 | 기준일 이후 12개월 |
| 정보 기준 시점 | 기준일 장 시작 전 |

예를 들어 기준일이 `2025-10-31`이면 뉴스·시장 분석 범위는 `2024-10-31~2025-10-30`이다. DART는 기준일 전에 접수된 공시만 사용한다. 실제 보고서는 형식 참고용이며, 기준일 이후에 작성된 보고서 내용을 예측 입력에 넣지 않는다.

수정은 `FINAL`에서 진행했다. 이 작업으로 `ABLATION`의 평가 코드나 기존 실험 결과를 갱신하지는 않았다.

## 2. 데이터별 변경 내용

### 2.1 뉴스: 월별 요약 12개와 핵심 사건

1년치 기사 원문을 분석 에이전트마다 반복해서 전달하지 않도록 입력을 제한했다.

- 기존 주별 중복 병합과 후보 15건 → 재정렬 후 최대 5건 선별을 유지한다.
- 선별된 사건을 12개 월 구간으로 묶어 요약한다.
- News Agent의 주 분석 입력은 월별 요약 12개와 전체 상위 사건 최대 20건이다.
- 다른 에이전트에는 동일한 월별 요약 12개를 subdata로 제공한다.
- 요약은 2~4문장·400자 이내를 요청하며, 600자 초과나 기간 누락·중복은 실패 처리한다. 핵심 이슈는 월별 최대 3개다.

월 구간은 기준일에 맞춘 연속된 12개 구간이다. 달력의 매월 1일~말일과는 다르며, 예를 들어 `2024-10-31~2024-11-29`, …, `2025-09-30~2025-10-30`처럼 실제 시작일과 종료일을 표시한다. 윤년과 월말을 보정하여 전체 1년을 빠짐없이 다룬다.

선별된 뉴스가 없는 구간도 남긴다. 이 표시는 해당 기간에 사건이 전혀 없었다는 뜻은 아니다. 월별 요약은 `NEWS_PERIOD`, 구체적인 원문 사건 근거는 `NEWS_RAW`로 구분하며 출처 연결을 보존한다. 월별 요약의 종료일을 사건 발생일로 해석하지 않는다.

분석 입력의 크기를 제한해도 수집·임베딩·재정렬·요약 생성 비용은 증가할 수 있다. 따라서 기간이 4배가 됐다고 최종 입력 토큰이 반드시 4배가 되는 것도 아니고, 전체 실행 비용이 고정되는 것도 아니다.

### 2.2 yfinance: 1년 분석과 시장 지표표

수집 기간을 늘리는 것과 함께 연간 흐름을 판단할 지표를 추가했다. 주 분석에는 연간 지표, 월별 관측치 12개, 최근 20거래일 관측치를 제공한다. 지표 계산을 위한 기존 2년 이상 준비 데이터는 유지하고 분석 범위는 1년으로 제한한다.

공통 시장 subdata는 다음 16개 숫자를 담은 표 1개다.

| 지표 | 개수 | 정의·단위 |
|---|---:|---|
| 주가 수익률 | 4 | 1·3·6·12개월, % |
| KOSPI 수익률 | 4 | 같은 1·3·6·12개월, % |
| 시장 대비 초과수익률 | 4 | 주가 수익률 − KOSPI 수익률, %p |
| 1년 변동성 | 1 | 일별 수익률 표본 표준편차 × √252, % |
| 1년 최대 낙폭 | 1 | 1년 내 이전 고점에서의 최대 하락폭, 음수 % |
| 현재 낙폭 | 1 | 현재 종가 / 1년 내 최고 종가 − 1, % |
| 최근 거래량 배율 | 1 | 최근 5거래일 평균 / 60거래일 평균, 배 |

실제 기준 거래일·종가·벤치마크·가격 기준도 함께 전달한다. 수익률은 배당을 제외한 공급자의 분할조정 종가를 사용한다. 상장 이력이 짧아 연간 수익률을 계산할 수 없으면 결측으로 남긴다.

120·200일 이동평균 대비 위치, 이동평균의 최근 20거래일 변화, 1년 가격 범위 내 위치는 시장 주 분석에 추가로 제공한다. 자료가 없는 월도 12개 구간 안에 `unavailable`과 결측값으로 표시한다.

### 2.3 DART: 3개 연도와 재무 추세표

주 분석에 최신 정기공시, 전년 같은 기간, 3개 연도 재무제표와 사업 내용을 활용하도록 반영했다. 공통 재무 subdata는 다음 8개 지표의 추세표 1개다.

| 지표 | 단위·산식 |
|---|---|
| 매출액 | 억원 |
| 매출 증가율 | 전년 같은 기간 대비, % |
| 영업이익 | 억원 |
| 영업이익률 | 영업이익 / 매출액 × 100, % |
| 순이익 | 억원 |
| 영업현금흐름 | 억원 |
| 자본총계 | 해당 기말 잔액, 억원 |
| 부채비율 | 총부채 / 자본총계 × 100, % |

열은 최신 3개 연도와 최신 누적 실적·전년 같은 누적 실적으로 구성한다. 최신 공시가 연간 보고서이면 같은 연도 열을 중복하지 않는다.

연간 실적은 직전 연간 실적과, 반기·분기 누적 실적은 전년 같은 누적 기간과 비교한다. 중간 연도가 빠진 자료는 전년 대비 증가율로 계산하지 않는다. 자본이 0 이하인 부채비율이나 비교 기간이 없는 증가율은 결측으로 처리한다. 대상 기간, 접수일, 공시 번호, 연결·별도 범위를 보존한다.

## 3. 공통 subdata 전달 방식

수신자별로 내용을 다시 선별하거나 별도 요약 에이전트를 추가하지 않았다. 동일한 출처의 subdata는 두 수신 에이전트에 같은 내용으로 전달한다.

| 수신 에이전트 | 받는 subdata |
|---|---|
| Financial Agent | 뉴스 월별 요약 12개 + 시장 지표표 1개 |
| News Agent | 재무 추세표 1개 + 시장 지표표 1개 |
| YFinance Agent | 재무 추세표 1개 + 뉴스 월별 요약 12개 |

생성 로직은 `src/shared/subdata.py`에 모았다. 각 에이전트의 결론은 담당 자료에 근거하고, subdata는 자료 사이의 정합성·충돌과 해석 한계를 점검하는 보조 문맥으로 사용한다.

## 4. Strategy와 최종 보고서 변경

기본 판단 프로필을 `annual`, 판단 기간을 `12개월`로 설정했다. Strategy v5의 개정 식별자는 `schema_revision: 12m_v1`이다.

| 주요 출력 필드 | 내용 |
|---|---|
| `headline` | 핵심 판단을 담은 제목 |
| `recommendation` | Buy / Hold / Sell |
| `thesis` | 투자 판단의 핵심 논거 |
| `earnings_review` | 최근 실적 검토 |
| `outlook` | 향후 12개월 전망과 전제 |
| `price_assessment` | 현재 가격 평가 |
| `counterview` | 반대 근거 |
| `decision_limitation` | 판단에 영향을 주는 자료·해석 한계 |

목표주가·미래 EPS·컨센서스를 투자 판단의 필수 조건으로 요구하지 않는다. 자료에 없는 숫자를 생성하지 않으며, 자료가 부족하다는 이유만으로 Hold를 기본값으로 강제하지 않는다. 문장별 근거 연결은 유지한다.

최종 HTML은 실제 보고서의 제목·투자의견·실적 검토·전망 구성을 참고하여 다음 내용을 표시한다.

1. 핵심 제목, 매수·중립·매도 의견과 12개월 판단 기간
2. 투자 의견과 핵심 논거
3. 최근 실적과 가격 평가
4. 핵심 판단 근거 최대 3개
5. 향후 12개월 전망과 전제
6. 핵심 위험 최대 3개와 자료 기준·한계

Writer는 Strategy의 투자의견을 그대로 표시한다. HTML의 `investment-recommendation` 메타 필드에도 Buy / Hold / Sell을 보존한다. 기존 판단 기간을 명시적으로 선택하는 CLI 옵션은 남겨 두었다.

## 5. 재검토에서 발견하여 수정한 문제

처음 구현한 뒤 11개 테스트가 통과했지만, 후속 재검토에서 추가 실행 경로를 확인하면서 다음 6개 문제를 재현하고 수정했다.

| 문제 | 수정 내용 |
|---|---|
| 최신 공시가 사업보고서일 때 전년 비교가 비어 있음 | 직전 연간 공시를 비교 대상으로 연결 |
| 연간 자료의 중간 연도가 빠져도 전년 대비 증가율로 계산 | 기준·기간 유형·기말과 정확히 1년 차이인지 확인 |
| DART 재사용 시 과거 1개 연도 경량 자료와 이전 지표를 그대로 복사 | 저장된 원본에서 현재 계산기로 재무 지표와 3개 연도 subdata 재생성 |
| 과거 3개월 전체 자료를 1년 분석에 재사용 가능 | 기업·기준일·분석 범위·가격 기준·연간 지표·월별 요약 구간 검증 |
| 월별 뉴스 요약의 종료일을 사건 발생일로 표시 | 요약 기간을 보존하고 원문 보도일과 구분하여 Strategy·Writer에 전달 |
| 시장 관측치가 없는 월을 생략 | 12개 구간을 유지하고 결측 상태 명시 |

추가로 다음 사항을 보강했다.

- 보고서의 LLM 입력을 만들기 전에 기준일 이후 시장 관측치를 제거한다.
- 기준일 당일 또는 이후 접수된 공시는 재사용하지 않는다.
- 전체 자료 재사용 시 시장 manifest의 기준일도 보존하고, 날짜가 붙은 요약에서 공통 별칭과 시장 subdata를 생성한다.
- 전체 시장 JSON·CSV, manifest와 subdata를 실행 결과 해시에 포함하여 원자료가 바뀌면 분석 캐시를 무효화한다.
- 재사용 원본은 수정하지 않는다.

## 7. 수행한 검증
