# 인용 근거 보존 및 후처리 상한 정리

적용일: 2026-09-09. 모든 ablation 조건에 같은 코드를 적용한다.

## 변경

- Strategy 본문·위험·보충 분석에 실제로 인용된 유효 근거를 개수 제한 없이 문맥 목록에 연결한다. 기존 10개 상한과 문단별 13개 참조 상한을 제거했다. 반복 인용은 목록에 한 번만 등록하며 본문은 바꾸지 않는다.
- 핵심 근거 3개, 위험 3개, 비교 지표 2개 같은 편집상 제한은 실행 실패 조건으로 사용하지 않는다. 핵심 근거와 위험의 수는 프롬프트 권장량으로 안내한다.
- 하위 분석에서 이미 인용한 뉴스 사건을 Strategy 입력 작성 중 다시 상위 몇 개로 제한하지 않는다. 재무·비교 카드와 판단 한계의 개수 기반 절삭도 제거했다. 기존 도메인별 카드 수 목표 초과는 telemetry 경고로 남긴다.
- Writer의 문단·주장 수에 대한 생성 스키마 상한을 없앴다. 작성 문단을 합치거나 누락 주장 목록으로 대체하지 않는다. 누락된 명시적 주장만 덧붙이고 기존 설명을 보존한다. 판단 한계 항목에도 같은 원칙을 적용한다.
- Writer가 선택한 사용 가능한 차트는 모두 생성·표시한다. 2개는 권장량이다. 전체 파이프라인 완료 검사에 중복되어 있던 2개 상한도 제거했다. 차트 설명 220자 초과는 근거 오류가 아닌 비차단 경고다. 기존 본문 전체 글자 수 검사는 이미 비차단 경고였으며 이를 유지한다.
- Strategy 정합성 처리 전에 원응답과 요청 지문을 `strategy_response_attempts`에 저장한다. 정합성 처리 실패 시 원응답 경로와 실패 단계를 별도 기록한다. 실패한 응답을 정상 결과로 등록하거나 임의 수정하지 않는다.
- Strategy 캐시 10, Writer 캐시 15·정규화 12, 차트 목록 v3로 변경했다.

## 유지

실험의 뉴스 수집·선택 수, 12개월 범위와 3개년 재무 입력, 모델·출력 토큰 설정은 바꾸지 않았다. 존재하지 않는 참조, 참조 중복, 데이터 형식, 날짜·공시·비교 기준, 출처 해시와 미완성 API 응답 검사는 유지한다. 입력·출력의 실제 모델 용량 제한이나 평가 모델 토큰 초과를 임의로 무시하지 않는다. Python이 투자 의견을 바꾸거나 특정 실험 조건에 유리한 근거를 추가하지 않는다.

현 실행 경로는 Strategy v5다. v4 등 과거 계약의 실행하지 않는 검증 코드를 일괄 삭제하지 않았으며, v5에서도 호출하는 공통 입력 작성 경로는 이번 수정에 포함했다. `report_context_cards`를 모델이 빈 배열로 반환하는 규칙은 중복 목록 작성을 피하기 위한 형식이다. Python이 실제 인용을 제한 없이 채우므로 최종 근거 수 상한이 아니다.

## 검증

- 15·30·60개 인용의 생성 스키마 수용, Strategy 정합성·Writer 전달 보존, 반복 처리 동일성.
- 미등록·중복 참조 실패, 후처리 실패 원응답·이력 보존.
- 다수 핵심 근거·위험, 뉴스 사건 15개, 판단 한계 12개 보존.
- 8개 본문 문단과 누락 주장 동시 보존, 긴 차트 설명 경고, 세 번째 차트 출력.
- 코웨이 저장 입력 재구성: 뉴스 사건 11개 모두 전달, 개수에 따른 누락 0건, Strategy 입력 약 18,108토큰. 실제 API 재실행은 별도 실행 기록으로 관리한다.
- 최종 오프라인 테스트: FINAL 43개, ABLATION 73개 통과.
- 코웨이 실호출: 핵심 근거 5개·문맥 근거 16개 보존. 본문 인용 21개 모두 Writer 입력에 남았고 본문 10문단·차트 3개가 출력됐다. 전체 완료 검사 수정 후 캐시 재사용으로 추가 호출 0건, 비용 $0에 완료됐다.
