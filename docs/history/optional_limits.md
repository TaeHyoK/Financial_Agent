# 판단 한계 선택 작성

수정일: 2026-09-09

## 변경 내용

자료의 기간·출처·확정 수준은 보존하되, 그것을 판단 한계로 설명할지는 분석 모델이 결정한다. 한계 문장의 감소나 특정 투자 의견을 성공 조건으로 삼지 않는다.

1. 뉴스의 `financial_link_status=not_observed`에 따라 재무 기여의 시점·규모가 확인되지 않았다는 문장을 자동으로 붙이지 않는다. `news_financial_link` 필수 설명 항목과 처음 두 카드만 연결하던 처리도 제거했다. 이전 패킷에 남은 해당 항목은 새 Strategy/Writer에서 다시 활성화하지 않는다.
2. 일반 월별 뉴스 카드의 독자용 표시에서 재무 기여 확인 불가 문구를 제거했다. 기간과 자료 유형은 유지한다. 뉴스의 원래 확정 수준·재무 연계 상태·보도일·기간은 Writer의 `source_metadata`에도 보존한다. 상태값이 없다고 미확인으로 추정해 문장을 만들지 않는다.
3. 하위 에이전트는 해석의 방향·강도·범위를 실질적으로 제한하는 사항만 `limitation` 또는 `data_limitation`에 작성한다. 없으면 빈 문자열을 허용한다. 관련 쟁점 자체가 없으면 기존처럼 빈 평가 배열을 허용한다.
4. Strategy의 `decision_limitation`은 `{"text": "", "card_keys": []}`를 허용한다. 실질적 한계를 작성할 때는 어떤 핵심 추론이 어떤 가정에 의존하는지 설명한다. 정상 공시 시차와 과거 재무표에 후행 사건이 반영되지 않은 사실만을 한계로 반복하지 않도록 지침을 보완했다. `counterview`, 실제 위험, 근거 충실도와 판단 확신도는 유지한다.
5. Writer는 Strategy v5의 한계 설명을 직접 편집하고 문장별 출처를 연결한다. Strategy 원문을 후처리로 덧붙이는 경로는 사용하지 않는다. 작성할 한계와 필수 자료 기준이 모두 없으면 빈 문단·주장 배열을 반환한다. 빈 항목을 `데이터 추가 필요`로 대체하지 않고 HTML 영역·소제목도 숨긴다.
6. 실제로 사용한 부분 공시표의 범위나 서로 다른 기준일의 가치평가 등 필요한 자료 기준 표시는 유지한다. 이는 사건을 자동으로 불리하게 해석하는 것과 다르다.

검증은 형식·실제 참조·표시 여부에 한정한다. 빈 한계에 근거만 남은 경우, 알 수 없는 근거를 참조한 경우는 오류다. Strategy가 한계를 실제로 제공했는데 Writer가 해당 설명을 모두 생략한 경우도 오류로 알리되, 문장을 자동 생성하거나 내용을 분류해 고치지 않는다. LLM이 의미상 과도한 판단을 하는지까지 이 검증이 보장하지는 않는다.

- `src/Agent_Team/Writer Agent/writer_handoff.py`: 독자용 문구와 원래 자료 상태 분리.
- 같은 디렉토리의 `html_report_writer.py`, `html_report_spec.py`, `formatted_html_renderer.py`, `html_report_validator.py`: 빈 항목 처리·직접 편집·선택 표시·검증 일치. Writer 캐시 버전 16.

필드 자체는 유지하고 빈 값을 허용하여 기존 출력 구조와 호환했다. 프롬프트와 스키마를 함께 조정한 것은 [OpenAI 구조화 출력 지침](https://developers.openai.com/api/docs/guides/structured-outputs#all-fields-must-be-required)을 참고했다. 모델이나 토큰 예산은 변경하지 않았다.

## 검증 범위

FINAL 회귀 테스트 78개, ABLATION 회귀 테스트 79개 통과. 빈 한계의 스키마·파서·HTML 정상 처리, 의미 있는 설명 보존, Strategy 원문 중복 삽입 방지, 뉴스 자료 상태 보존, 필요한 공시 범위 표시를 확인했다.

Full·Random·No-sub·One team은 공통 지침과 파서를 사용한다. One team의 기존 동등성 테스트도 통과했다. 이번 변경으로 뉴스 선정·요약·가중치·모델·투자 의견 기준을 바꾸지 않았다. 이전 결과와 새 결과를 섞지 말고 새 실험 디렉토리에서 평가해야 한다.

개발용 실호출 입력은 기존 SK바이오팜 가중치 실험의 기준일 2025-11-06 자료다. 원본 파일의 해시는 유지했다. 하위 분석은 한 차례 생성하고, 그 결과를 고정한 채 Strategy/Writer를 두 차례 실행했다. 이후 두 번째 Strategy 결과를 고정한 채 Writer만 추가 검증했다. 비교기업 분석은 기존 입력을 재사용했으며 뉴스 수집·요약·선정, 비교기업 재분석, 차트 생성, 조건별 성능 평가는 수행하지 않았다.

## 실호출 관찰

- 하위 분석의 보조자료 평가 10개 중 6개는 `limitation`을 빈 문자열로 작성했다. 시장 3개, 재무 1개, 뉴스 2개다. 본문에는 제품 집중과 규제·안전성 위험이 유지됐다. 빈 항목의 개수는 동작 확인이며 품질 점수가 아니다.
- 일부 하위 분석은 여전히 재무 기여액 부재·공시 시차를 별도 한계로 설명했다. 일반론이 모두 사라진 것은 아니다.
- 첫 Strategy는 선택 작성이 가능해도 반기 공시에 후행 뉴스 효과가 반영되지 않았다는 일반론을 작성했다. 코드 후처리가 아닌 LLM 생성임을 원래 응답에서 확인했다.
- 이에 정상 공시 시차와 판단의 핵심 추론을 구분하는 공통적인 Strategy 지침을 보완했다. 두 번째 Strategy는 제품의 판매·허가 확대가 수익성으로 이어진다는 가정, 확장 효과와 안전성 부담의 크기를 구분하기 어렵다는 판단으로 바뀌었다. 여전히 효과의 크기·시점에 대한 보수적 서술이 남아 있으므로 이것만으로 충분히 구체적인 분석이 완성됐다고 보지는 않는다.
- 상대수익률로 시장 신뢰나 실적 반영 정도를 추론하거나, 비교 기준이 부족한 배수를 높다고 해석하는 문장도 남았다. 이번 수정은 한계의 자동 삽입과 작성 강제를 제거하는 작업이지 이러한 의미상 과잉 해석까지 해결한 것은 아니다.
- 두 번째 보고서의 Writer가 Strategy에 없던 정상 공시 시차 설명을 추가한 것을 확인했다. 선택된 판단 한계와 지정된 자료 기준만 편집하도록 Writer 지침을 보완하고, Strategy 응답을 그대로 재사용해 Writer만 재호출했다. 문장 삭제용 규칙은 추가하지 않았다.
- 최종 Writer에서는 정상 공시 시차 문단이 빠지고 선택된 성장 가정과 효과 규모의 불확실성을 한 문단으로 편집했다. 한계 문장은 LLM이 선택해 남아 있으며, 전망에도 ‘재무 기여 규모와 시점은 아직 확인되지 않았다’는 표현은 남았다. 고정 문구의 제거와 유사한 표현의 완전한 소멸은 다르다. 모든 뉴스 카드 3개에서 `source_metadata`가 Writer 입력에 보존된 것도 확인했다.

세 번의 검증용 보고서 모두 HTML 검증을 통과했다. 최종 보고서의 한계 영역은 실제 내용이 있으므로 표시된다. 빈 한계 영역을 숨기는 경로는 회귀 테스트에서 별도로 확인했다.
