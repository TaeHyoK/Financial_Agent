# 통합 분석 보존과 의견 전용 단계 실험

작성일: 2026-09-09. 운영 파이프라인은 변경하지 않는다.

## 목적과 범위

이전 2단계 실험에서는 의견 없는 분석이 지표 간 차이를 설명했지만, 다음 Strategy 호출에서 전체 본문을 다시 쓰면서 일부 비교가 누락됐다. 이번에는 분석을 독립 산출물로 보존하고 의견 단계의 업무를 최종 의견, 선택 이유, 핵심 근거, 위험 및 명시적인 오류 수정으로 제한한다.

`scripts/compare_preserved_analysis.py`에서 이전 two_stage r01·r02의 분석을 각각 그대로 재사용한다. SK바이오팜, 기준일 2025-11-06, GPT-5.4, 원래 관측과 하위 분석 전체는 동일하다. 두 번째 단계와 Writer만 새로 실행한다. 이전 분석 생성 비용은 이번 사용량 합계에서 제외한다. 추가 자료 수집·비교기업 재실행·전체 ablation·운영 전환은 하지 않는다.

## 전달 구조

- `analysis_original.json`: 앞선 의견 없는 분석 원본. 수정하지 않는다.
- `decision_only_raw.json`: 최종 의견·선택 이유와 수정 요청. 실적·전망·가격 문단을 다시 생성하는 필드는 없다.
- `analysis_effective.json`: 모델이 명시한 오류 구절만 고친 분석. 나머지 문장과 인용은 보존한다.
- `writer_strategy_projection.json`: 기존 Writer 계약을 이용하기 위한 연결 파일이다. 분석과 의견을 조합한 것이며 하나의 LLM 응답으로 표시하지 않는다. 작성 주체는 `projection_provenance.json`에 기록한다.
- `writer_context.json`: 수정된 분석 전체와 의견 결과를 각각 전달한다. Writer는 중요한 관계·대비·가정을 유지하면서 중복과 문장을 편집한다. 분석 원문 전체를 최종 HTML에 강제로 붙이지 않는다.

수정은 모델이 지정한 정확한 원문 구절, 대체 문구, 이유와 근거로 구성한다. 원문과 일치하지 않거나 수정 구간이 겹치면 오류를 알리고 중단한다. 의미를 추측해 보정하거나 특정 투자 의견으로 바꾸는 규칙, 인용 개수 상한, 원하는 결과가 나올 때까지의 재생성은 없다. 이 검사만으로 수정 내용의 타당성이 검증되는 것은 아니므로 실제 문장을 읽고 평가한다.

OpenAI Docs 스킬의 [구조화 출력 지침](https://developers.openai.com/api/docs/guides/structured-outputs#all-fields-must-be-required)을 따라 필드를 명시하고 선택적 수정은 빈 배열로 표현한다.

## 사전 평가 기준

1. 두 반복 모두 중요한 지표 관계가 수정 후 분석과 최종 보고서에 유지되는가.
2. 사업 전망과 가격 판단을 구분하고, 근거 없는 가격 반영 추정이 줄어드는가.
3. 최종 의견의 선택 이유가 위험·성장 요인의 존재를 나열하는 수준을 넘는가.
4. 원래 분석 오류를 유지하지 않고, 수정이 근거에 맞는가.
5. 한계 반복·과도한 분량·내부 식별자 노출이 없는가.
6. 입력·인용 보존과 형식 검증 결과를 내용적 품질과 구분하는가.

이전 two_stage 결과에도 같은 기존 Writer를 실행해 비교한다. 이는 고정된 두 중간 분석에 대한 개발용 비교이며 동일 계산량 실험이나 성능 향상 입증이 아니다. 단일 기업에서 좋은 결과만 골라 운영에 반영하지 않는다.

## 직접 읽은 결과

두 의견 전용 응답 전체와 수정 기록, 네 HTML 보고서의 본문·표를 직접 읽었다. 아래 평가는 내용 검토이며 화면 렌더링이나 전체 차트 검증은 아니다. 이번 실행은 차트를 새로 생성하지 않았다.

### 확인된 개선

- 실적·전망·가격 분석은 의견 단계에서 다시 쓰지 않았다. r01은 전망의 비한국어 표현 한 구절만 모델이 수정했고, r02는 수정 요청이 없었다. 분석에서 인용한 서로 다른 카드 23개·27개가 각각 전달용 근거 목록까지 보존됐다.
- 기존 r02 본문은 현금흐름도 손익과 같은 방향으로 개선됐다는 설명에 머물렀다. 새 r02는 영업현금흐름률과 영업이익률의 차이, 수익성 개선이 같은 강도로 현금에 나타난 것은 아니라는 해석을 유지했다. 기존 r01에도 이 비교는 이미 있어, 두 반복에서 새로 개선된 것으로 과장하면 안 된다.
- 새 보고서는 두 반복 모두 중요한 실적 비교를 유지했다. 다만 r02 본문에서는 해당 비율의 구체적인 숫자가 표로 이동했고, 이익률과 현금흐름률의 '개선 폭' 비교가 수준 차이 설명으로 약해졌다. 분석 보존과 최종 표현의 정밀함은 별개다.
- 별도 판단 한계는 두 새 의견에서 빈 항목이었고 HTML도 해당 절을 만들지 않았다. 한계를 Python이 삭제한 결과는 아니다.

### 해결되지 않은 문제

1. **의견 선택의 깊이**: 두 새 의견 모두 제품 집중도와 안전성·규제 민감도를 실적 개선보다 중요하게 본다. 그러나 노출이 크다는 사실에서 중립으로 넘어가는 설명이 길어졌을 뿐, 어떤 사업 가정 때문에 성장의 지속성을 낮게 평가하는지는 충분하지 않다. 다변화가 매수의 필수 조건처럼 취급되는 경향이 남았다. Hold 자체가 틀렸다는 뜻은 아니다.
2. **가격 추론**: r02 의견에 최근 반등이 실적·허가 뉴스에 대한 단기 반응일 수 있다는 해석이 남았다. 과거 상대성과와 미래 상승여력 사이의 연결 근거는 여전히 약하다. 새 구조만으로 인과 추정이나 의견의 근거 부족이 해결되지는 않았다.
3. **오류 수정의 신뢰성**: r01은 비한국어 표현만 고쳤다. r02 원본의 `financial_link_status`, `not_observed`는 수정되지 않았고 Writer 입력까지 남았다. 최종 본문에는 이 두 키가 나오지 않았지만 `reference only`가 노출됐다. r01 원본의 일부 초과수익률 단위와 강한 가격 해석도 의견 단계의 수정 대상에 포함되지 않았다. 빈 수정 배열을 무오류 판정으로 해석하면 안 된다.
4. **한계 반복**: 별도 한계 절은 사라졌지만 전망·리스크에 미래 기여 규모 미확인 표현은 남았다. '한계 문구가 없어졌다'가 아니라 일부가 다른 절에 남아 있는 결과다.
5. **표의 편집 경로**: 새 r01 핵심 근거 표에는 `Buy보다 Hold`, r02에는 `Hold 판단`이 그대로 나타났다. 현재 표가 Strategy의 해석을 직접 표시하는 경로여서 Writer의 한국어 본문 편집만으로 고쳐지지 않는다. 이번에는 규칙 치환으로 숨기지 않고 원래 결과를 보존했다.
6. **비교기업 배치**: 새 보고서의 실적·가격 절에 유한양행 비교가 들어갔다. Writer 지침의 비교 배치 제한과 달라, 형식 검증 통과가 편집 지침 전체 준수를 뜻하지 않는다.

수준 차이만으로 현금 전환의 원인이나 이익의 질 악화를 확정할 수 없다는 점도 유지해야 한다. 새 r01의 '현금화 속도'는 기간 합계 자료로 속도까지 입증한 것처럼 읽힐 수 있다.

## 입력량 증가 원인

Writer만 비교하면 입력 토큰이 기존 27,073/26,511에서 새 56,590/58,538로 늘었다. 분석이 길어진 데 더해 다음과 같은 반복이 있다.

- 기존 연결 함수가 비결정 카드의 해석에 연결된 분석 문단 전체를 넣는다.
- 같은 문단이 여러 카드와 의견 연결 필드에 반복된다.
- 이번 실험의 독립 분석·의견 필드가 기존 전달용 필드와 일부 중복된다.

r02 Writer 입력에서는 1,128자 가격 문단이 13회, 1,531자 실적 문단이 10회, 1,399자 전망 문단이 7회 반복됐다. 기존 r02도 각 분석이 여러 번 반복됐지만 문단이 짧아 증가폭이 작았다. 따라서 분석 내용을 자르는 대신, 본문은 한 곳에서 보존하고 카드에는 분석 참조를 연결하는 전달 구조가 필요하다.

표·제목을 제외한 본문 길이는 기존 r01/r02 1,950/1,733자에서 새 2,231/2,203자로 늘었다. 입력 증가가 그만큼 독자에게 유용한 설명 증가로 이어진 것은 아니다.

## 결론과 다음 작업

분석을 보존하는 방향은 유효하지만, 이번 구현을 운영 기본값으로 전환하지 않는다. 분석 전달 문제와 의견 선택 문제를 분리해 다뤄야 한다.

1. Writer 전달 형식에서 동일 분석의 중복 복사를 제거한다. 원문·인용은 한 번만 보존하고 참조로 연결한다. 실제 근거를 자수나 개수로 자르지 않는다.
2. 의견 단계에서는 최종 결론을 특정 방향으로 유도하지 않고, 기본 사업 전망과 다른 의견이 요구하는 가정의 차이를 비교하게 한다. 위험 노출과 실제 전망 하향을 구분하고, 과거 상대수익률을 미래 수익성의 대체 근거로 삼지 않도록 판단 업무를 명확히 한다.
3. 보고서 표의 해석도 한국어 독자 문장으로 편집할 수 있도록 출력 책임을 정리한다. 분석 의미를 Python이 다시 쓰지는 않는다.
4. 위 변경은 새로운 실험 이름으로 같은 두 입력에서 비교한다. 개선이 유지되는지 확인한 뒤 다른 기업에 적용하고, 그 전에는 전체 ablation의 기본 경로를 변경하지 않는다.
