# 분석 중심 Strategy 변경 및 검토

수정일: 2026-09-09

## 목적

같은 입력으로 관측 간 관계를 더 잘 설명하고, 그 분석을 바탕으로 의견을 선택하도록 한다. 특정 투자 의견이나 Full 우승을 유도하지 않는다. 이번 변경은 한 번의 Strategy 호출 구조를 유지한다.

## 구현

### 입력

- `evidence_cards`: 관측·자료 카드. 모델 요약 여부와 원천 수치, 기간, 출처를 보존한다.
- `domain_handoffs`: 하위 에이전트의 해석. 기존 내용을 그대로 보존하며 Strategy가 근거와 대조해 수용·보완·수정할 수 있다고 설명한다.
- `applicability_notes`: 기존 `data_limitations`를 명시적 카드 키가 있는 항목과 공통 항목으로 나눈다. 정확히 동일한 항목만 합치며, 의미를 추측해 삭제하거나 부정적 자료를 제외하지 않는다. 카드 키를 해소할 수 없는 항목도 공통 항목에 원형 그대로 남긴다.
- `input_roles`로 위 역할을 설명하고 관측 자료를 하위 해석보다 앞에 배치한다. 카드 자체의 기간·출처·주의사항도 남긴다. 보고서 projection에도 적용 범위를 보존한다.

이번 고정 입력은 기존 대비 **관측 카드와 하위 해석이 완전히 동일**하며, 기존 주의사항 16개도 모두 보존됐다. 따라서 자료를 줄이거나 악재를 제거해서 생긴 변화가 아니다. 의미가 유사하나 표현이 다른 주의사항까지 자동 병합하지는 않았다.

### Strategy

출력 스키마의 순서를 실적 검토 → 전망 → 가격 평가 → 대안 설명 → 선택 이유 → 의견·제목·요약으로 변경했다. 근거 선택 목록은 분석 결과 뒤에 둔다. 기존 필드로 처리하며 별도 분석 에이전트나 재검토 호출은 추가하지 않았다.

프롬프트는 다음을 분석의 중심으로 삼는다.

- 수치 증가·감소 나열보다 서로 뒷받침하거나 엇갈리는 관측의 관계를 설명한다.
- 기업별로 중요한 비교를 선택하며 특정 지표 조합을 의무화하지 않는다.
- 사업 전망, 가격 매력, 판단 확신을 구분한다.
- 확인된 변화와 미래 가정을 구분하고, 가정을 채택한 이유를 근거로 설명한다.
- 위험 노출 범위가 크다는 사실을 위험의 현실화나 성장 효과 상쇄와 동일하게 취급하지 않는다.

`relation_to_decision`의 supports/opposes/limits 분류는 새 계약에서 제거했다. `investment_implication`으로 근거의 사업상 의미와 최종 판단에 미치는 영향을 설명한다. 중요도는 모델이 작성하되 점수나 개수로 합산하지 않는다.

핵심 근거와 본문 인용은 구분한다. 핵심 표는 통상 1~3개를 중심으로 선택하되 필요한 근거를 개수 때문에 제외하지 않는 편집 지침이다. 본문 인용에는 상한이 없고, 표에 쓰지 않은 인용은 문맥 근거로 보존된다. 실제 최종 시험에서도 핵심 근거 4개가 그대로 유지됐다.

### Writer 및 검증

- 근거 표를 `핵심 근거 / 확인된 수치·사실 / 투자 판단에 미치는 의미`의 세 열로 변경했다.
- 새 계약에서는 지지·반대 역할 메타데이터와 표시를 생성하지 않는다. 과거 계약을 읽는 경로는 유지한다.
- 표의 해석은 Strategy LLM이 작성한 의미를 보존한다. Python이 새로운 투자 의견을 만들거나 근거 역할을 재판정하지 않는다. 기존 수치 표시와 표 조립은 유지한다.
- Writer는 선택 이유를 서두에 전달하고 실적의 변화 원인·강도, 전망의 지속성·가정을 보존하도록 했다. 같은 한계를 여러 절에서 반복하도록 요구하지 않는다.
- 검증은 구조, 참조, 자료 보존을 확인한다. 특정 의견이나 금융 해석을 정답으로 강제하는 규칙은 추가하지 않았다.

현재 Strategy 계약은 `12m_v3`, Strategy 캐시는 14, Writer 캐시는 18이다. 과거 Strategy 결과는 새 계약으로 재생성해야 한다. 기존 Writer의 v1/v2 입력 읽기는 유지한다.

OpenAI Docs 스킬을 사용해 프롬프트와 구조화 출력의 순서를 함께 맞췄다. 구조화 출력은 스키마 키 순서를 따르지만, 그 자체가 논증의 개선을 보장하지는 않는다. [공식 문서: 구조화 출력의 키 순서](https://developers.openai.com/api/docs/guides/structured-outputs#key-ordering).

## 검증 범위

- FINAL 94개, ABLATION 79개 회귀 테스트 통과.
- 신규 테스트 8개: 자료·해석 불변, 주의사항의 무손실 분리, 출력 순서, 의견·서술 보존, 역할 분류 제거, 기본·자유 형식 표 계약, 이전 Writer 호환, projection 적용 범위 보존.
- 기존 12개 추가 인용 보존 테스트도 통과했다.
- GPT-5.4, 기존 생성 설정과 뉴스 가중치를 유지했다.
- 하위 분석과 비교기업 자료를 고정한 SK바이오팜 기준일 2025-11-06 입력을 사용했다. 비교기업 재실행·뉴스 재수집·차트 생성·ablation 평가를 수행하지 않았다.

기준 파일: `/home/agent2/ABLATION/experiments/optional_limits_20260909_live/normalized_domain_bundle.json`

이전 비교 대상: `/home/agent2/ABLATION/experiments/decision_rationale_20260909_r01`, `decision_rationale_20260909_r02`

## 단계별 결과

1. `analysis_first_20260909_r01`, `analysis_first_20260909_r02`: Strategy만 두 번 실행했다. 비용률 변화와 사업 전망을 더 길게 설명했으나 가격 반영에 대한 과도한 추론이 남았다. 핵심 근거를 13개·14개 선택해 표와 문맥의 구분이 약해졌다.
2. 표의 선택 지침을 보완했다. 기존 1~3개 중심의 편집 권고를 복원하고, 모든 본문 인용을 핵심 표에 넣을 필요가 없다는 점을 명시했다. 자료·의견 기준·가중치·생성 설정은 바꾸지 않았다. 앞의 실패 결과는 그대로 보존했다.
3. `analysis_first_20260909_final_r01`: 수정 지침으로 Strategy를 다시 실행했다. 핵심 근거 4개, 보충 문맥 14개가 보존됐다. 의견은 Hold다. 원하는 의견이 나올 때까지 재실행한 것이 아니며, 위 재실행의 목적은 표와 문맥의 구분 보완이다.
4. `analysis_first_20260909_report`: 3번의 저장된 Strategy 응답을 재사용해 Writer만 실행했다. 완료됐으며 HTML 차단 오류는 없었다. 원본 입력과 재사용 Strategy 파일의 해시가 변경되지 않았다.

## Strategy 정성평가

### 개선 확인

- 실적 검토에서 매출 증가와 이익 증가의 강도 차이를 언급하고 공헌이익률·판매관리비율 변화로 설명한다.
- 사업 전망을 긍정적으로 보면서 가격 매력은 별도로 제한적으로 평가하는 구분이 더 명확해졌다.
- 표의 분류 라벨과 본문 의미가 충돌하는 구조를 없앴다.

### 미해결

- 영업이익률과 영업현금흐름률의 개선 폭 차이를 깊게 비교하지 않는다. 이번 예시에서 중요한 차이를 실제로 활용했다는 성공 판정은 할 수 없다.
- 최종 Strategy의 “현재 가격은 사업 개선 기대를 일부 반영” 등은 과거 수익률만으로 충분히 뒷받침되지 않는다. 기준일 가격의 의미를 추정하는 문제가 남았다.
- 집중도와 안전성 경고를 더 중요하게 보는 이유는 전사 파급 범위로 설명하지만, 왜 확인된 성장보다 우선하는지는 여전히 약하다.
- “추가 검증이 필요한 중립 구간”, 이후 뉴스의 재무 기여 미확인 같은 표현이 남았다. 코드가 삽입한 문장이 아니라 모델이 작성했다. 의미 검증을 통과했다고 주장하지 않는다.
- 초기 r02의 순이익·EPS 증가를 근거로 일회성 의존을 약화시키는 표현, “드문 사례”라는 비교 범위 없는 표현도 과도했다. 최종 결과만 제시해 초기 결함을 숨기지 않는다.

현재 판정은 **구조와 전달은 개선됐으나 분석 깊이의 개선은 제한적**이다. 순서 변경만으로 사후적 의견 정당화가 해결됐다고 볼 수 없다. 한 기업의 개발용 검토이며 일반적인 성능 향상이나 Full 우위를 입증하지 않는다. 다음에 추가 실험을 한다면 작성 지침을 계속 늘리기보다, 의견을 정하지 않는 분석 산출과 의견 선택을 분리하는 방식의 비용·품질을 고정 입력에서 비교하는 것이 후보가 된다. 이번에는 그 추가 호출 구조를 도입하지 않았다.

## 최종 Writer 검토

`analysis_first_20260909_report/report_payload.json`의 전체 본문과 두 표를 직접 읽었다.

- 세 열 표에 핵심 근거 4개가 표시되며, 지지·반대 라벨 없이 Strategy의 투자 판단상 의미가 유지됐다. 본문 문맥 근거 14개도 Writer 입력으로 보존됐다.
- 실적 문단에 공헌이익률·판매관리비율 변화와 이익 증가 폭의 관계가 남았고, Strategy의 판단을 가른 논리도 서두에 전달됐다.
- 그러나 “장기 상대성과 부진과 과열권 모멘텀은 일부 기대가 이미 반영됐을 가능성”이라는 약한 가격 추론도 그대로 전달됐다. Writer의 충실한 전달이 원래 해석의 타당성을 보장하지는 않는다.
- 촉매와 판단 한계에 미래 재무 기여 미확인이 반복됐다. 마지막 한계 문단의 9~11월 뉴스 흐름 표현은 월별 요약 카드의 실제 기간과 주장별 연결도 추가 점검이 필요하다. 이 검토에서 새로운 외부 사실을 보충하거나 문장을 수동으로 고치지 않았다.
- 관측 표가 상세해 본문과 수치가 중복되는 부분은 남는다. 표의 수치 표시 체계 자체는 이번 변경 범위에서 바꾸지 않았다.
