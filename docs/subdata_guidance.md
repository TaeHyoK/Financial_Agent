# 하위 에이전트 보조자료 활용 지침 보완

작성일: 2026-09-09

후속 변경: 한계 문구의 자동 삽입·필수 작성을 제거한 현재 동작은 [판단 한계 선택 작성](optional_limits.md)에 정리했다. 아래 실호출 결과는 해당 후속 변경 전 기록이다.

## 변경 원칙

보조자료를 문맥·한계 설명에만 사용하는 제약을 해제했다. 다른 도메인의 자료로 주 자료의 중요도, 지속성, 위험과 종합 판단을 보강하거나 수정할 수 있다. 원래 수치·발생 사실·출처·확정 수준은 바꾸지 않는다.

연결할 만한 근거가 없으면 사용하지 않아도 된다. 보조자료 부재를 악재로 간주하거나, 자료가 있다는 이유만으로 결론을 바꾸도록 요구하지 않는다. 판단 내용은 LLM이 작성하며 Python이 긍정·부정 방향을 강제하지 않는다.

## 구현

| 부분 | 변경 내용 |
| --- | --- |
| 공통 지침 | `src/shared/subdata_guidance.py`에 사실과 해석의 구분, 자료 기간 확인, 실제 활용 근거 연결, 종합 요약 반영 지침을 모았다. |
| 재무 분석 | 뉴스의 사업 변화·보도 실적과 공시 추세를 연결하고, 시장자료는 재무 흐름과 가격 흐름의 일치·괴리를 해석하는 데 사용한다. 가격 부진만으로 영업 실적의 지속성을 낮게 판단하지 않도록 했다. |
| 뉴스 분석 | `news_only`의 뉴스 근거 분석과 별도로 `overall_assessment`를 추가했다. 재무·시장 보조자료를 결합한 경제적 의미는 이 종합 판단에 작성한다. 발표된 실적과 전망을 구분하고, 숫자가 실제로 들어 있는 기사·기간 요약을 인용하도록 했다. |
| 시장 분석 | 같은 기간의 월별 뉴스와 가격·거래량·초과수익률을 대조한다. 월별 요약 종료일을 사건 발생일로 간주하거나 월간 수익률을 특정 사건 이후 수익률로 해석하지 않는다. |
| 출력 형식 | 재무·시장 보조자료 평가를 도메인별 단일 객체에서 쟁점별 배열로 변경했다. `judgment_impact`에 해석에 미친 영향을, 종합 판단의 `context_ids`에 사용한 쟁점을 기록한다. |
| 검증 | 자료 식별자·도메인·참조 관계를 확인한다. 관련 쟁점이 없으면 빈 배열을 허용한다. 쟁점·인용 근거 개수의 고정 상한은 두지 않았으며, 기존 API 출력 토큰 예산은 유지했다. |
| Strategy 전달 | 쟁점의 주 자료와 보조자료를 실제 근거 카드에 연결한다. 기존 카드에 없는 인용 자료는 출처·기간·작성 방식을 보존한 참고 카드로 추가한다. 매칭 실패 시 임의로 해당 도메인의 첫 카드에 붙이는 처리는 제거했다. |
| 실제 입력 정리 | Strategy 입력 정리 과정에서도 뉴스 종합 판단, 보조자료 원래 구조와 기간 정보가 유지되도록 수정했다. |
| 비교기업·Writer | 비교기업 뉴스 분석 카드에도 종합 판단을 포함했다. Writer에 전달되는 뉴스 참고 카드에는 실제 요약 내용과 기간을 유지한다. |

새 활용 표지는 `context_informed_interpretation`, 지침 버전은 `context_interpretation_v3`이다. 이전 `framing_and_limitation_only` 결과는 읽기 호환을 유지하되 새 방식으로 작성된 결과인 것처럼 바꾸지 않는다. Strategy v5 캐시 버전은 11로 올렸다.

프롬프트에서 요구하는 내용과 구조화 출력의 필수 필드를 함께 변경했다. 형식 준수와 내용의 사실성 검증은 별개로 취급한다. 구조화 출력 구성은 [OpenAI 공식 문서](https://developers.openai.com/api/docs/guides/structured-outputs)를 참고했다.

## 실험 조건의 공통 적용

- Full과 Random은 동일한 분석 지침을 사용한다. Random 기사를 무조건 활용하게 하거나 불리한 결론을 요구하지 않는다.
- No-sub도 같은 분석 원칙을 사용하되 보조자료가 없는 입력과 빈 평가 배열을 허용한다.
- One team은 `ABLATION/ablation_suite/unified.py`에서 동일한 세 도메인 요청의 지침·입력·스키마를 묶는다. 이번 변경도 공통으로 적용되며, 모델·생성 설정과 합산 출력 예산의 동등성을 회귀 테스트로 확인했다.
- 대상기업과 비교기업은 동일한 하위 분석 코드를 사용한다. 이번 실호출 검증에서는 비교기업을 재생성하지 않았다.
- 뉴스 선정 알고리즘, 섹션 가중치, 원자료, 평가 지표는 이번 보완에서 변경하지 않았다. 모든 조건은 변경된 코드로 새 실험 디렉토리에서 다시 실행해야 한다. 기존 결과와 새 결과를 섞어 비교하지 않는다.

## 확인 결과

회귀 테스트는 FINAL 66개, ABLATION 79개가 통과했다. 이번에 추가한 FINAL 테스트 10개는 공통 지침, 빈 평가, 20개 쟁점·인용 보존, 잘못된 참조, 정확한 카드 연결, 입력 정리 후 보존 등을 확인한다.

SK바이오팜의 기준일 2025-11-06 가중치 실험 입력을 고정하고 GPT-5.4로 재무·뉴스·시장 분석을 두 차례 실행했다. 뉴스 선정·요약 생성은 다시 하지 않았으며 원본 입력 파일의 SHA-256이 변하지 않았음을 확인했다. 이는 하위 에이전트와 Strategy 전달 경로 검증이며, 전체 파이프라인·보고서·제거 실험 재평가는 아니다.

두 번째 결과는 세 도메인에서 각각 3개 쟁점을 생성했다. Strategy 카드 36개에 실제 인용 자료를 연결했다. 저장된 결과를 수정된 운영용 입력 정리 함수에 다시 통과시켰을 때 종합 판단·쟁점·카드 연결이 유지되는 것도 오프라인으로 확인했다.

### 직접 읽고 확인한 변화

- 재무: 공시의 매출 집중도와 뉴스의 주력 제품 안전성 경고를 연결해 실적 개선의 지속성 위험을 설명했다. 보도된 분기 실적은 공시 추세를 해석하는 자료로 구분했다.
- 뉴스: 3분기 매출 1,900억원·영업이익 700억원을 해당 숫자가 담긴 월별 요약에 연결했다. 실제 발표 실적은 `announced`, 전망 기사는 `reported_expectation`으로 구분했다. 과거 국내 허가 대기는 후속 허가로 해소됐음을 표시했다.
- 시장: 2025-10-06~2025-11-05 뉴스와 동일 월간 성과를 대조하고, 재무 개선을 추세 해석의 배경으로 사용했다. 개별 사건과 일간 수익률의 인과를 확인한 것으로 쓰지는 않았다.

### 남은 한계

- 재무 종합 판단에는 상대수익률 부진으로부터 ‘재무 개선이 주가에 전면 반영됐다고 보기 어렵다’는 표현이 나왔다. 이 자료만으로 반영 정도를 측정한 것은 아니므로 해석이 근거보다 앞서는 사례다.
- 뉴스는 이미 해소된 허가 대기를 현재 위험에서는 제외했지만, 과거 불확실성 설명을 별도로 남겨 다소 장황하다.
- 일부 쟁점은 `context_ids`와 별도 설명에 비해 종합 요약에서 영향이 충분히 드러나지 않는다. 참조의 존재 자체를 실질적 활용이나 품질 향상으로 평가하면 안 된다.
- 한 기업의 두 차례 개발용 실행이다. Full의 성능 우위나 Random 대비 개선을 입증하지 않는다. 다음 검증은 입력을 고정한 조건별 전체 보고서 생성·평가가 필요하다.
