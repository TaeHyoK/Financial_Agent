# 영역 간 보조자료

각 전문 에이전트는 담당 영역의 관측 자료를 주 근거로 사용하고, 다른 두 영역의 자료는 해석의 정합성·충돌·적용 범위를 점검하는 문맥으로 사용한다. 다른 에이전트의 결론을 원자료의 사실처럼 취급하지 않는다.

공통 보조자료는 월별 뉴스 요약, 시장 지표표, 재무 추세표다. 수신자별 추가 선별 없이 동일한 내용과 값을 전달한다. 뉴스 에이전트에는 선정 기사 전체를 주 자료로 전달하고, 재무·시장 에이전트에는 같은 기사로 만든 월별 요약을 보조자료로 전달한다.

관측 자료, 하위 해석, 자료의 기간·범위·한계를 구분한다. 사건 보도일과 요약 기간을 혼동하지 않으며, 연간 실적과 반기·분기 누적 실적은 동일 기준이 아니면 직접 비교하지 않는다. 입력에 없는 목표주가·미래 실적·확정 인과관계를 생성하지 않는다.

보조자료가 담당 영역의 해석을 실제로 바꾸는 경우 근거와 의미를 설명한다. 관련성이 약하거나 자료가 충돌하면 무리하게 연결하지 않는다. 단순 참조 ID의 수가 분석 품질을 의미하지 않는다.

전달 구조와 지표 정의는 [뉴스 입력](news_article_only.md)과 [12개월 분석 설계](annual_analysis.md)를 참고한다. No-subdata 제거 실험은 [Ablation 방법](../ablation/docs/ABLATION.md)에 정의한다.
