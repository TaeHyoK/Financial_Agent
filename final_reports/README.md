# Final research reports

멀티에이전트 금융 의사결정 프레임워크의 최종 보고서 HTML 75개다. 각 파일에는 차트가 포함되어 있어 내려받은 HTML 하나로 브라우저에서 열 수 있다.

- 회차: `r01`, `r02`, `r03`.
- 조건: `full`, `random_news`, `no_subdata`, `no_peer`, `one_team`.
- 기업: 현대건설, 두산, BGF리테일, 아모레퍼시픽, SK바이오팜.
- 경로: `r0N/<조건>/<기업>.html`.

대표 예시는 [현대건설 Full 보고서](r01/full/현대건설.html)다. 보고서에는 기준일, 12개월 투자의견, 실적·가격 검토, 핵심 근거, 전망, 위험과 자료 한계를 표시한다.

[실험 조건](../ablation/docs/ABLATION.md)과 [평가 결과](../ablation/results/README.md)는 `ablation/`에 있다. 공개 파일의 SHA-256 및 평가 기록과의 대응은 [report_manifest.json](report_manifest.json)에서 확인한다. 평가 지표는 새로 계산하지 않았다.

이 보고서는 연구·정보 제공 목적이며 투자 권유가 아니다. 실제 애널리스트 PDF, API 키와 내부 실행 자료는 저장소에 포함하지 않는다.
