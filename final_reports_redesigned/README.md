# final_reports_redesigned

논문 ablation 의 최종 보고서 75개를 현재 보고서 디자인으로 다시 그린 판이다. 경로는 `r0N/<조건>/<기업>.html` 로 [`final_reports/`](../final_reports/README.md) 와 같다.

논문이 평가한 파일은 `final_reports/` 의 HTML 이다. 이 폴더는 같은 내용을 읽기 좋게 다시 그린 것이며, `ablation_results/` 의 `report_sha256` 과는 대응하지 않는다.

## 만든 방법

- 원래 실험에서 저장한 Writer 응답을 그대로 쓰고, 응답 뒤 단계(정규화, 차트 생성, 렌더링)만 `main`(커밋 `f9d8e7e`)의 코드로 다시 돌렸다. 모델은 부르지 않았다.
- 차트는 보고서의 원래 자료로 현재 차트 코드가 다시 그렸다. 보고서별 차트 수와 차트 설명은 원래와 같다.

## 원래 보고서와 같은 것

- Writer 가 쓴 문단 646개가 모두 그대로 있다. 빠지거나 더해진 문단은 없다.
- 평가에 쓰는 본문(`real_report_evaluation/extract.py` 로 뽑은 서술 본문)은 74개가 원래 평가 본문과 바이트까지 같다. `r01/full/아모레퍼시픽.html` 한 개는 한 문장의 `Sell` 이 `매도` 로 바뀌었다.
- 투자의견은 75개 모두 원래와 같다.

## 원래 보고서와 다른 것

- 머리 띠, 핵심 지표 패널, 차트 위치, 글꼴과 간격이 현재 디자인이다.
- 표 안의 투자의견을 매수/중립/매도로 표시하고 내부 필드 이름을 드러내지 않는다. 끝의 고지문은 현재 문구다.
- 핵심 지표 패널의 시가총액, P/E, P/B 는 현대건설, 두산, 아모레퍼시픽, SK바이오팜에서 지금 계산한 값이다. 원래 실험 코드는 이 네 기업의 기준일 가치평가를 계산하지 못했고, 그 결함은 뒤에 고쳤다. 이 숫자는 원래 실험 산출물에 없었다. 본문과 근거 표에는 넣지 않았다.
  - 시가총액은 기준일 직전 종가에 보통주 수를 곱한 값이다. 우선주는 넣지 않았다.
  - 최근 12개월 지배주주 순이익이 0 이하이면 P/E 를 `적자` 로 적는다.
- One-team 보고서 8개의 근거 표에서 통합 분석 카드는 관측 문장만 보인다. 원래 보고서는 해석 문장과 내부 필드 이름까지 함께 찍었다.
