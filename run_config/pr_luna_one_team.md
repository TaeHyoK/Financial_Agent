## 변경 내용

월별 뉴스 요약과 기업 분석에 서로 다른 모델을 지정할 수 있도록 연결한다. 기본 실행에서는 월별 뉴스 요약에 GPT-5.6 Luna를, 재무·뉴스·시장 분석과 비교 분석·Strategy·Writer에 GPT-5.4를 사용한다. 선정 뉴스 전체는 뉴스 분석에 전달하고, 월별로 생성한 12개 요약은 재무·시장 보조자료로 제공한다.

- One-team 조건의 단일 통합 분석과 후속 비교·Strategy·Writer 연결 구성요소를 추가한다.
- 캐시 입력·캐시 쓰기와 모델별 비용을 집계하고 월별 요약 호출 수를 실행 명세에 반영한다.
- 비교기업 차트의 결측값을 숫자형 NaN으로 유지하여 차트 생성 오류를 해결하고, 누락된 EPS를 0으로 표시하지 않는다.
- README의 모델 설정과 코드 구성을 갱신한다. 서버 전용 실행기가 없는 환경에서는 해당 실행기 테스트만 건너뛴다.

실험 데이터, 반복 실행 보고서, 평가 결과, 서버 전용 실행기와 API 키는 커밋에 포함하지 않는다.
