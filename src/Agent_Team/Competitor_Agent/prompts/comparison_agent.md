# 비교 분석 과업

대상기업과 선정 비교기업에 대해 각각 산출된 재무·뉴스·시장 분석과 동일 기준의 수치 자료를 함께 검토하라. 비교기업을 단순 수치표로 축약하지 말고, 두 기업에서 관찰된 실적 흐름, 재무상태, 주요 사건, 가격·상대성과가 어떻게 다른지 종합한다.

- 판단은 입력된 `basis_cards`에만 근거한다. 외부 사실이나 수치를 보충하지 않는다.
- 재무·시장 수치는 두 기업의 기간과 산출 기준이 일치할 때만 우열 판단에 사용한다. 기준이 다르거나 값이 없으면 한계로 남긴다.
- 뉴스는 각 기업의 사건과 불확실성을 비교하는 데 사용하되, 재무적 영향이 확인되지 않은 사건을 실적이나 주가의 원인으로 단정하지 않는다.
- 하위 에이전트가 제공한 교차 영역 평가는 보조 문맥이며 다른 영역의 직접 근거를 대신하지 않는다.
- 대상기업의 상대적 강점, 상대적 약점, 혼재된 차이 또는 양사 공통 요인 중 입력에서 확인되는 사항만 제시한다. 결론의 방향을 미리 정하지 않는다.
- 각 비교 항목은 실제로 사용한 근거 카드와 그 근거가 필요한 이유를 `basis`에 기록한다.
- `comparison_brief`에서 사용한 근거도 `comparison_brief_basis`에 별도로 기록하며, 비교 항목이나 이 근거에서 확인되지 않는 내용을 요약문에 추가하지 않는다.
- `buy`, `hold`, `sell`, 매수, 보유, 매도, 목표주가 또는 투자 행동 지시는 쓰지 않는다. 이 단계는 상대적 위치를 분석하는 단계이며 최종 전략 판단 단계가 아니다.
- JSON key는 스키마대로 영어로 쓰고 모든 분석 문장은 한국어로 작성한다.
