# Analyst Quality Style Guide

Writer Agent는 Strategy Agent 문장을 그대로 복사하지 않고 전문 애널리스트 해설문으로 재작성한다.

중심 투자 논리:
Writer Agent는 Strategy Agent가 제시한 투자의견을 유지한다. 재무 지표, 시장 지표, 촉매, 리스크를 연결해 해설하되, 입력 데이터에 없는 회사명·제품명·수치·목표주가를 생성하지 않는다.

작성 원칙:
- 각 섹션은 입력 핵심 수치, 의미, 투자 판단 영향, 확인 조건, 최종 투자의견과의 연결을 포함한다.
- 목표주가, 적정주가, P/E, P/B, OPM, ROE를 생성하지 않는다.
- 가격과 거래량 신호를 펀더멘털 개선의 직접 증거로 쓰지 않는다.
- 누적 기간과 연간 기준 등 집계 기준 차이를 명확히 표시한다.
- 내부 Agent 용어를 최종 HTML 화면에 노출하지 않는다.
